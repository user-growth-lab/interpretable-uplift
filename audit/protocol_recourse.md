# E2: prespecified recourse diagnostic (2026-09-28)

This protocol is saved before computation. It diagnoses target feature states of a fixed fitted model; it does not establish that a person can take actions to reach those states. Historical search and a minimally filtered search are reported separately. The original submitted files remain unchanged.

- Data: semi-synthetic IHDP replication 0 with five seed-selected modifiers, and Hillstrom pooled email versus no email, visit outcome. Seeds 42–46. Preserve the original S10 loaders (Hillstrom preprocessing fitted on the full covariate table before the outer split); explicitly label this historical preprocessing protocol. No test outcomes enter preprocessing. IHDP uses its supplied train/test partition and training-only standardization. Hillstrom outer split is 80/20; choose 8,000 training rows using the run seed. This protocol does not claim Hillstrom preprocessing is train-only; E3 examines that separately.
- For each seed choose the same 50 test rows for all methods with `default_rng(seed).choice(..., replace=False)`. Fit the existing default T-learner once. Save teacher, row IDs, raw point pairs, predictions and feature names.
- Methods and historical settings: Greedy (step .1, max 20 steps, max 3 changed coordinates, proximity .1), Gradient-CF (step .1, max 50 steps, finite difference .01, five line-search steps, proximity .1), RandomSearch (2,000 candidates, L2 distance budget 3, proximity .3). Use identical 1st/99th percentile training boxes. No claim of equal computational budgets.
- A second version adds candidate rejection using the same declared domain for every method. No projection/rounding repairs an illegal candidate. Every nominal or binary field is held fixed; Hillstrom recency is also held fixed, and history must remain inside the unchanged history_segment's original interval. IHDP's 19 binary baseline fields are fixed; its six continuous coordinates remain mathematical target coordinates. Hillstrom's only free coordinate is history within its existing band. These are deliberately conservative *declared frozen fields*, not verified immutable features or feasible actions. Past measurements cannot be changed by an intervention at baseline. Original states outside the box remain in the denominator and may return unchanged. Candidate generation budgets stay fixed; rejections consume candidates.
- Type schema: IHDP features x0–x5 continuous and x6–x24 binary (values determined from training data); Hillstrom history continuous, recency integer, mens/womens/newbie binary, history_segment/zip_code/channel nominal represented by dropped-first one-hot groups. Raw values and encoding are reconstructed from the same source rows. Derived history bands are checked without rounding or using outcomes.
- Mixed distance: mean across original variable groups; continuous coordinates use absolute difference divided by training IQR, discrete/nominal variables use 0 for the same valid category and 1 otherwise. A one-hot group has one weight. Invalid fractional category vectors count as different from every reference category. Zero IQR falls back to training range, then 1; record every fallback. Distances are not clipped to 1.
- Split the fitted teacher's training rows into 80% reference and 20% calibration with `default_rng(seed+10000)`. Fixed k=5. Use the **fifth-nearest-neighbor distance**; threshold is its 95th percentile among calibration rows measured against reference rows. The original and recommended test points share the same reference and threshold. Neither threshold nor k is chosen using test outcomes or observed success.
- Tolerances: coordinate/type checks 1e-7, no-op maximum coordinate change <=1e-7, strict positive gain >1e-9, nonnegative gain >=-1e-9. No-op is never successful recourse. A diagnostic success requires changed, legal, and strictly positive model gain.
- Save all inputs and outputs, including invalid candidates returned by historical search and initial box failures. Report initial/final fifth-NN distances and changes, exceedance, type/derived/frozen/box validity, no-op, strict positive and nonnegative rates, changed original-variable groups and predicted gain. Report all-input diagnostic success and support conditional on changed legal outputs (and its denominator). Support is empirical proximity, not a causal or real-world feasibility guarantee.
- Aggregate within each seed, then give mean and between-seed SD. The 250 evaluated rows across repeated seed runs are not 250 independent trial units. No significance contest and no favorable-seed selection.
